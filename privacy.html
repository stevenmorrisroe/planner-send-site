Privacy policy: crew planner send

Last updated 2026-11-25.

Who uses it

crew planner send is a private tool used by one person, its owner, with his own Google account. It is not offered to the public.

What Google data it accesses

It requests only the https://www.googleapis.com/auth/gmail.send scope. It uses that scope to send emails the owner has written and approved. It does not read, search, list, change or delete any email, contact or other Google data.

How the data is stored

The OAuth token is stored only on the owner's own computer, in a file readable by his user account alone. The planner keeps a record of each email it sent: the recipients, the subject, the time and Gmail's message id. That record stays on the same computer.

Sharing

No Google user data is sold, shared, or transferred to anyone. It is not used for advertising or to train any model. The use of information received from Google APIs follows the Google API Services User Data Policy, including its Limited Use requirements.

Removing access

The owner can revoke access at any time at myaccount.google.com/permissions. Deleting the token file on his computer also removes it.

Contact

For questions, open an issue on this site's GitHub repository.
